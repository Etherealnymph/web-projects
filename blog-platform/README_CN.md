## 项目简介

博客平台是这个集合里唯一的服务端应用。它依赖 Node.js、Express 与 MongoDB，不能部署到 GitHub Pages，因为登录、邀请码校验和权限控制都在 Express 层执行。

## 功能

- 账号存放于 MongoDB，使用邮箱 / 密码注册登录和服务端 session。
- 仅限邀请码注册：只有 `role=superadmin` 账号能通过 `POST /admin/invites` 生成一次性邀请码。
- 超管后台可管理账号、邀请码与内容维护。
- 服务端渲染视图、静态资源与文件上传。
- 通过环境变量配置：`MONGODB_URI`、`SESSION_SECRET`、`NODE_ENV`。
- 执行 `npm ci && npm start` 即可启动，默认端口 12399。
