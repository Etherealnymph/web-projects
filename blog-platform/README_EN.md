## Overview

Blog Platform is the only server-side application in this collection. It needs Node.js, Express and MongoDB, and cannot run on GitHub Pages, because login, invite checks and role permissions are enforced in the Express layer.

## Features

- Email/password accounts stored in MongoDB, with server-side sessions.
- Invite-only registration: only a `role=superadmin` account can mint one-time invite codes through `POST /admin/invites`.
- Admin console for accounts, invites and content maintenance.
- Server-rendered views, static assets and file uploads.
- Environment-driven configuration: `MONGODB_URI`, `SESSION_SECRET`, `NODE_ENV`.
- One-command start with `npm ci && npm start`; the default port is 12399.

## Project structure

```text
blog-platform/
├─ server.js              # Express app: sessions, invites, uploads, admin routes
├─ package.json
├─ views/                 # server-rendered templates
├─ public/                # static CSS / JS / images
├─ scripts/               # maintenance and seeding scripts
├─ uploads/               # user uploads (keep out of production snapshots)
├─ README_ORIGINAL.md    # original deployment notes
└─ README.md / README_EN.md / README_CN.md
```

Original detailed notes (Chinese): [README_ORIGINAL.md](README_ORIGINAL.md).

## Boundaries and notes

- Never commit `.env`, `uploads/` or logs. GitHub Pages only publishes files, so deploying this folder there would expose the source and data without access control.
