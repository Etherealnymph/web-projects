## 项目简介

词典把常用核心词汇和电子工程 / IC 专业术语放在一起：详细中英对照释义、词形变化与相关词、例句、美式 / 英式音标与真人发音。星标词条的例句取自电影台词或名人名言，并注明出处。

## 功能

- 1,684 个主词条、4,711 个变形 / 相关词、479 个专业领域词条、48 条名言 / 台词，以及美式 / 英式双发音。
- 支持英文或中文检索，按词性和领域（数字、模拟、器件工艺、EDA、嵌入式、电源）筛选。
- 词形变化可点击跳转同族词，支持随机查词复习。
- 完全离线：直接打开 `index.html`，词库按需从本地数据分片加载。
- 数据校验脚本与冒烟测试保证发布前各分片一致。
