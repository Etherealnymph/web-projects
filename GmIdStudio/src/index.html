使用说明

30 秒上手

  1. 左侧选择 工艺角 / NMOS-PMOS / 电压域，设定 L、W、VDS 与体偏。
  2. 在 VGS · GM/ID 图上点击任意曲线点，右侧探针会锁定坐标并显示工作区、VTH、gm·ro、ID/W、fT。
  3. 切换 L 扫描 查看不同沟道长度的本征增益族；切换 自定义 组合任意 X/Y 指标。
  4. 用 导出 → Spectre 测试台 在真实 BSIM3 仿真器中复核曲线。

工作区判据

截止区VOV < −120 mV，沟道未形成
亚阈值区−120 mV ≤ VOV < 50 mV，指数型电流
线性/三极管区VOV ≥ 50 mV 且 VDS < VDSAT
饱和区VOV ≥ 50 mV 且 VDS ≥ VDSAT

模型与方法

页面内嵌原始 rf018.scs（gzip），启动时由浏览器解析 Spectre section、parameters 与 BSIM3 binned model card，并用 VTH0 / K1 / K2 / TOX / U0 / VSAT / RDSW / PCLM 等参数驱动 EKV 型电荷模型与 α-power 饱和模型。gm、gds 由数值微分得到。

这是面向 gm/Id 设计空间探索的快速参数化引擎，不等同于完整 BSIM3 直流求解。版图寄生、温度、噪声与高阶短沟道效应未包含；最终签核请以 Spectre 为准。
