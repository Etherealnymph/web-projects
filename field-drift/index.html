原理手册

0 · 你在玩什么

你驾驶一枚带电探针，在一片充满电磁场的空间里漂移。你没有强引擎，只有一个很弱的推进器； 真正让你移动、转向、加速的，是场。每关目标：收集散落的电荷种子，穿过场锁门，抵达出口。

为什么不是"沿电场线走、看到电荷就标记"？
因为那只是一个观测任务，你不需要做任何决策。真正好玩的问题不是你在哪，而是你以什么速度、在什么参考系里。 本作把它做成了核心机制：有些门，只认速度。

1 · 唯一的运动方程

探针质量 m、电荷 q，在黏滞介质中受到正比于速度的阻力。整个游戏只有这一条方程：

m·dv/dt = q(E + v×B) − kv

稳态（dv/dt = 0）时令 μ = q/k，有 v = μ(E + v×B)。解得的速度既不沿 E 也不沿 B， 而是从 E 方向被拧开一个角度：

tan θH = μB = qB/k

这叫 霍耳角。磁场唯一能做的事，就是把你的速度从电场方向"拧"开。B 越大拧得越多，B 反向则往另一边拧。 HUD 里的 θH 就是它。

游戏采用自然单位 c = 1，所以 β 与速度数值相同；高 β 时加速度会乘 1/γ，速度被硬性限制在 c 以下。

2 · 磁场不做功

磁场力 qv×B 永远垂直于 v，所以功率 P = F·v = 0。 磁场无法改变你的速率，只能改变方向。你所有的加速都来自电场和推进器， 而两者都要花场能。仔细观察能量条：关掉 B 只会改变轨迹，不会改变能量收支。

3 · 无受力速度与静默门

找一个速度使电场力与磁场力恰好抵消：

q(E + v×B) = 0  ⟹  v* = (E×B) / B²

以这个速度飞行时，你感受不到场——两股力互相抵消，探针沿直线滑行。这就是等离子体物理里的 E×B 漂移速度，也是"磁场能把粒子冻在磁力线上"的经典图像的另一面。

静默门只在你通过时"场力≈0"才解锁，判定量：

δ = |E + v×B| / (|E| + |v×B|)

δ → 0 即静默。门会先亮起一圈进度，稳定 0.6 秒后永久解锁。

4 · 为什么有些门永远打不开：不变量

如果你无论怎么飞 δ 都降不下去，HUD 会提示 E·B ≠ 0。原因是：

(E + v×B)·B = E·B

只要 E·B ≠ 0，无论取什么速度，磁场方向的电场分量都消不掉。E·B 是洛伦兹不变量。 另一族不变量决定 E 和 B 谁能被"消掉"：

E·B = 不变    |E|² − |B|² = 不变    (c = 1)

  • |E| > |B| 且 E·B = 0 → 存在 E′ = 0 的参考系（纯磁场系）
  • |E| < |B| 且 E·B = 0 → 存在 B′ = 0 的参考系（纯电场系）
  • E·B = 0 且 |E| = |B| → 任何参考系都消不掉，只剩一个以 c 传播的平面波

5 · 换系：同一个场，两副面孔

按 空格 你瞬间改变速度 Δv。这不只是冲刺——你换了一个参考系， 于是你看到的场全部变了：

E′∥ = E∥    E′⊥ = γ(E⊥ + v×B)
B′∥ = B∥    B′⊥ = γ(B⊥ − v×E)
γ = 1/√(1 − β²)

按 F 在"站台系"与"我的参考系"之间切换可视化：同一片空间，箭头完全变了样。 哪一个是"真的"？都不是。E 和 B 只是同一个电磁场张量 Fμν 在不同参考系下的两组分量。

6 · 磁场就是电场的相对论效应

取一根通电导线：静止晶格带正电、电子以速度 u 漂移，整体电中性。站台系里你看到电流产生 B， 旁边的运动电荷受磁力 qv×B。

换到电荷自己的参考系：晶格与电子的洛伦兹收缩比例不同，净电荷密度 ρ′ ≠ 0——导线居然带电了。 电荷受到的是纯电力 qE′。同一个力，两种说法。

因为 γ ≈ 1 + ½β² 中的 β² 很小，磁力比电力小约 v²/c² 倍——这就是"磁场是电力的相对论修正"的准确含义。 在近光速的场海里，这个修正不再微小，于是你随时可以切换视角去读它。

关于 D 与 H：真空中 D = ε₀E、H = B/μ₀，只是换了个常数； 只有在介质中它们才携带独立信息（极化与磁化）。本作的场海是近真空等离子体，所以直接读 E 和 B。

7 · 动生电动势：你的燃料

你在磁场中飞行时，在你自己的参考系里出现了电场 E′ ≈ γv×B。收集器把它整流成能量：

P充能 ∝ |v×B| · γ

所以：想充电，就垂直于 B 高速飞行。这正是法拉第电磁感应定律的动生形式 ε = ∮(v×B)·dl。 靠近通电导线绕圈，就是本作最好的充电桩。

8 · 势：φ 与 A

场来自源。源一旦摆好，场和势就同时被确定：

φ(r) = Σ k qi/ri    E = −∇φ
A(r) = Σ k Ii ∫ dl/|r−r′|    B = ∇×A

按 V 在探针处切一个垂直于视线的平面：第一次是 φ 电势（蓝负红正，附等势线）， 第二次是 A 磁矢势（大小热图 + 方向箭头），第三次关闭。

看 A 最有意思的地方：它绕着电流打圈，螺线管轴线上 A 最小、B 最大——两个势与场并不"同向"。 A 不对应任何可感知的力，却决定了整个磁场，在量子力学里还直接与相位耦合（A–B 效应）。

切面跟着探针走，所以它像一台"场的显微镜"：飞到哪里，就在哪里采样。

9 · 场源与实验室

从标题页进入场实验室，可以在空间里直接放置源，场线与势会立刻重算：

点电荷 ⊕ / ⊖E = kqr̂/r²
电偶极子E = k[3(p·r̂)r̂−p]/r³
线电荷 / 带电面 / 带电柱由源离散叠加；柱外场等价于轴线线电荷 λ=ρπr²
线电流 / 电流环毕奥–萨伐尔积分（长直导线用解析解）
面电流 / 柱电流面电流 = 一排平行导线；空心柱电流内部 B≈0
螺线管N 个同轴电流环，内部近似匀强
磁偶极子B = k[3(m·r̂)r̂−m]/r³
匀强电场区 / 磁场区盒形区域内的常矢量场，边界软过渡
