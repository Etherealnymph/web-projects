# 场海 · Field Drift

本项目提供三种入口，均使用原生 JavaScript 和 Canvas，无运行时外部依赖。

- **物理直觉实验**提供九个有明确模型边界的案例。记录预测、调一个参数、观察轨迹与量化读数，再对照解释。
- **漂流关卡**保留七关导航玩法，使用电磁场、线性阻力、推进器和游戏补给机制。
- **场实验室**允许放置电荷、电流与区域场，观察场线及符合条件的势切面。

## 直觉实验

| 案例 | 模型 | 可改变内容 | 可观察内容 |
| --- | --- | --- | --- |
| 磁场与回旋 | 相对论洛伦兹力 | B、初速、电荷符号 | 转向、半径、动能 |
| 速度选择器 | 正交匀强 E、B | E、B、注入速度 | 两力抵消与偏转 |
| 阻力与霍耳漂移 | 洛伦兹力与线性阻力 | B、阻力 | 暂态与稳态偏角 |
| 单摆与小角近似 | 非线性单摆 | 初角、摆长、阻尼 | 与小角解析摆对照、能量交换 |
| 驱动与共振 | 受迫阻尼振子 | 驱动频率、阻尼 | 暂态、振幅、输入与耗散功率 |
| 抛体与空气阻力 | 重力与线性阻力 | 发射角、阻力 | 真空轨迹对照、射程与机械能 |
| 从圆轨道到逃逸 | 固定中心反平方引力 | 初速倍数 | 轨道形状、比能、比角动量 |
| 磁通与感应 | 外加正弦磁通、纯电阻回路 | 频率、电阻 | 磁通、电动势、电流、耗散功率 |
| 驻波与边界 | 两端固定的一维线性波 | 谐波阶数 | 波节、波腹、能量交换 |

所有案例默认暂停，通过同一入口开始、暂停、单步或重置。参数修改即重新初始化，方便比较相同初始条件。每次观察最多 40 秒，轨迹和历史最多各 1201 点。力学采用 SI 单位；电磁轨迹用 c=m=1；轨道、驻波的无量纲约定写在各自页面。每个案例显示方程和适用范围。图中矢量长度使用压缩映射，方向保真，数值以读数为准。预测文字只保留在当前页面，未写入存储。

## 数值与物理逻辑

漂流游戏采用 `dp/dt=q(E+v×B)−kv+F推进`、`p=γv`，用相对论 Boris 磁旋转代替旧的速度 Euler 更新与简单 1/γ 加速度修正。固定步长 1/120 秒，游戏速度上限仍为 0.93c。门的累计时间和通关计时使用实际完成的物理步长，慢动作同样影响门的计时。

实验轨迹使用 1/240 秒步长，电磁使用 Boris，机械模型使用 RK4，驻波与感应使用解析函数。数值计算有有限步长误差，尤其在强场、近奇点与超相对论运动中需要重新评估步长。测试覆盖此界面的受限参数范围。

以下条件影响解释。

- `E×B/B²` 是 E⊥B 时的横向电磁力抵消速度。它可叠加平行于 B 的速度，且需保证总速度小于 c。含阻力时它一般不等于稳态速度。
- 零场或静止于纯磁场时合力为零，δ 取零。静默门采用有限容差，因此根据实际 δ 判定，不能仅因 E·B 非零而否定任意容差下的抵消程度。
- E·B=0 且 B²>E² 时存在 E′=0 的惯性系，E²>B² 时存在 B′=0 的惯性系。非零零模场的局部不变量不足以判定它是平面波。
- 游戏补给是独立玩法资源。真实磁力功率为零，发电装置的能量来自外源并伴随反作用。
- F 视图是用探针瞬时速度进行的局部场变换。加速观察者的完整非惯性坐标系、场的空间同时性转换和传播延迟未建模。

## 场源及性能

固定线段几何在创建 Sources 时预计算。可编辑流线由单个 Web Worker 生成，队列保留一个正在执行的任务和最新待执行任务，过时结果不会覆盖新场。`file://` 或不支持 Worker 时回退到本线程。

势切面在场源、切面位置、朝向、范围或模式改变时更新，运动中的采样间隔至少 120 ms。静止的势切面复用缓存。Canvas 像素比最高 1.5，主画布总像素预算约 300 万。隐藏页面停止绘制和物理更新并挂起音频，暂停的直觉实验只在操作或缩放时重绘。一次性音频结束后断开节点。

软化点电荷、偶极子和有限线段有相应数值检验。局部匀强盒边界只作玩法塑形，未满足完整 Maxwell 场约束，因此含区域场时停用势切面。带电柱的轴线近似仅用于外部定性观察，不能表示真实有限柱内部场。A 的箭头依赖规范，不能理解为力线。所有场线也不等于粒子轨迹。

## 本地启动与验证

在仓库根目录运行 `python3 -m http.server 8123`，打开 `http://127.0.0.1:8123/field-drift/`。直接打开 index.html 也可使用，流线在本线程回退计算。

运行 `node --test field-drift/tests/*.test.cjs`。测试覆盖纯磁速率守恒、平行电场解析解、洛伦兹不变量、零强度源、势的梯度与旋度、机械能与角动量、抛体射程、感应、驻波以及所有案例参数边界。浏览器仍需检查输入、布局与真实运行性能。
