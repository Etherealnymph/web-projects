# 场海 · Field Drift —— 设计说明

> 一个把大学物理电磁学（含"磁场是电场的相对论效应"）变成核心机制的 3D 漂移游戏。
> 入口：`field-drift/index.html`，纯静态、无依赖、可直接双击打开。

---

## 一、先说原方案为什么不够好玩

原构想是：在空间里沿电场线 / **D** / **B** / **H** 前进，看到电荷就标记。

问题不在物理，在于**玩家的决策空间为零**：

1. **没有目标冲突**。沿场线走是"正确做法"，而你永远在做正确的事——这不是游戏，是可视化演示。
2. **没有失败代价**。标记错/看漏最多扣分，玩家不会紧张。
3. **"沿场线前进"是被动**。场线决定了你的路径，玩家只负责按下前进键。
4. **看不见的知识**。D 与 H 在真空里只是 E、B 乘个常数（D=ε₀E、H=B/μ₀），把它们做成三条并行的"轨道"不会产生任何新玩法。

诊断结论：**缺的不是物理内容，而是把一个物理量变成"必须争取的东西"。**

---

## 二、重新设计：把目标从"位置"换成"速度"

> **有些门，只认速度，不认钥匙。**

整个游戏围绕一个反直觉的事实展开：在正交的 E、B 场里，存在一个**唯一的速度**

```
v* = (E × B) / B²
```

以它飞行时，电场力与磁场力**恰好抵消**，你感觉不到场，探针沿直线滑行。
这个速度就是等离子体物理里的 **E×B 漂移速度**，也是"磁场把带电粒子冻在磁力线上"的经典图像的另一种说法。

于是有了本作的核心动词：

> **你不是要"到达"某个地方，你是要"以某个速度"到达某个地方。**

这一句话同时解决了两件事：
- **玩法**：把"导航"升级成"矢量匹配"——像对接空间站、像空中加油，天然有难度、有手感、有精度的快感。
- **教学**：玩家为了过关，**必须**理解 E、B 如何合成力，必须亲手算出 v* 的方向，必须体会"改变速度 = 换参考系"。

## 三、核心循环

```
观察场读数 (HUD) → 判断 v* / 霍耳角 → 用推进器与场力调整速度
      ↑                                            ↓
   收集种子 ←—— 沿场线滑行省能量 ←—— 穿过场锁门 / 躲开场蚀区
```

一局 60–120 秒，七关，评价按用时给金/银/铜。

**五个动词**，每个都对应一条大学物理：

| 动词 | 键 | 物理内容 |
|---|---|---|
| 推进 | `W/S/A/D` | 洛伦兹力 + 阻力；终端速度；磁场不做功 |
| 极性翻转 | `Q` | `q` 同时决定电场力与磁场力方向 |
| 换系冲刺 | `空格` | 瞬间改变自己的速度 Δv ⇒ 洛伦兹变换；γ 因子；速度上限 c |
| 参考系视图 | `F` | E′、B′ 的变换；不变量在眼前保持不变 |
| 慢动作 | `Shift` | 精调速度矢量（"时间膨胀"的玩法化） |

## 四、唯一的物理模型

整个游戏只有一条方程（自然单位 c = 1）：

```
m·dv/dt = q(E + v×B) − k·v
```

`−k·v` 是黏滞介质的阻力。这条方程让探针成为一枚"会飞的霍耳元件"：

- **稳态速度**从 E 方向被拧开一个**霍耳角** `tan θ_H = qB/k`。
  磁场唯一能做的事就是改变方向，而玩家要在意的正是方向。
- **磁场不做功**：`(qv×B)·v = 0`。HUD 的能量条只受电场与推进器影响，玩家可以亲眼验证。
- **无受力速度** `v* = E×B/B²` 是上面方程的零点，也是"静默门"的判据。
- **不变量**：`(E + v×B)·B = E·B`。只要 `E·B ≠ 0`，无论怎么飞都消不掉平行分量——于是有了"永远打不开的门"，这是把不变量做成关卡规则，而不是课堂结论。

实现上用了 `1/γ` 修正加速度并把速度硬性夹在 c 以下，所以高速时 γ、β 的读数与变换公式是自洽的。

> 为什么不用"真实"的回旋？因为在 20 单位大小的场区里，可见的回旋半径会让探针原地打转。
> 阻力介质（Drude/Hall 模型）既保留了全部电磁学结构，又给出了可控的稳态漂移 —— 这是为可玩性做的**物理上诚实的简化**，手册里写明了。

## 五、七关的教学弧

| # | 关名 | 教什么 | 玩法转折 |
|---|---|---|---|
| 01 | 电场之潮 | 洛伦兹力、终端速度 | 松手让场送你走 |
| 02 | 极性 | q 的符号 | 同一个场，换号即反向；上下穿行 |
| 03 | 霍耳角 | v×B 把速度拧开 θ_H | 自然航向不是 E 的方向，红色的场蚀区正好布在"高速公路"上 |
| 04 | 静默门 | `v* = E×B/B²`、δ 判据 | **第一道速度门**：把 δ 压到 0.15 并保持 |
| 05 | 不可消除 | `E·B` 与 `|E|²−|B|²` 不变量 | 两扇门，一扇永远打不开；先读数再飞 |
| 06 | 电流的两副面孔 | 动生电动势、磁力的相对论来源 | 关闭基础充能，必须垂直 B 高速飞行才能回血；`F` 键对照两个参考系的受力描述 |
| 07 | 统一 | 全部 | 更严的 δ、更小的触发半径、场蚀区与种子交错 |

每一关的简报都只讲"这一关需要的那一条"，手册里才有完整推导。

## 六、为什么这些机制"只有电磁学能给"

- **速度门**：只有 `q(E+v×B)=0` 这种**力互相抵消**的结构，才会产生"以特定速度抵达即无敌"的玩法。重力、摩擦力都给不出这么干净的零点。
- **换系 = 改变速度**：相对论让"冲刺"这个烂大街的动作变成一次**物理操作**——你改变的不是位置，是你眼中整个世界的场。按 `F` 看它变脸，是别的题材给不了的瞬间。
- **永远打不开的门**：`E·B` 不变量让"不可能"成为可以被玩家**证明**的东西，而不是策划写的规则。
- **燃料来自感应**：把"回血"绑在 `|v×B|` 上，玩家为了续航会主动去做"垂直于 B 高速飞行"这件物理上正确的事。

## 七、可玩性是怎么保住的

物理严谨不等于好玩，所以加了这些"手感层"：

- **准星 δ 环**：δ 越小，环越收紧、越绿；到了阈值会亮"静默 78%"。把一个抽象内积变成肌肉记忆。
- **金色 v\* 箭头**：从探针指出"无受力速度"的方向与大小，玩家只要把绿色速度箭头对准金色箭头。
- **场力箭头**：橙色，实时显示 `q(E+v×B)`，让"抵消"可见。
- **流动光点**：场线不是静态线条，而是沿场方向流动的短划痕——一眼看出方向与强弱。
- **失败代价**：场能同时是燃料与血条；耗尽或撞进红色场蚀区会解体，在起点重构（已收集的种子不丢），压力存在但不劝退。
- **慢动作**：精调速度时按住 `Shift`，把"手抖"从失败原因里剔除。

## 八、技术实现

- **零依赖**：没有 three.js、没有构建、没有网络请求。手写 3D 透视投影 + Canvas 2D 加法混合，因此 `file://` 直接双击可玩。
- **场是静态的，所以流线只算一次**：进关时用 RK2 沿 E、B 积分出上百条流线并缓存，每帧只做投影与描边。
- **参考系视图**：按 `F` 后在探针周围采样 3×3×3 的场，用洛伦兹变换把 E′、B′ 画成箭头阵列——同一片空间，箭头整个变了样。
- **渲染分层**：背景点阵/尘埃 → 墙体与场源 → 场线（加法混合，无序）→ 物体 → 探针 → 屏幕特效。
- 60 fps @ 1440×900，纯 CPU 绘制。

## 九、可编辑的场：源、势、实验室

前三章的游戏是"读场"，这一章补上"写场"。

### 9.1 补齐的源类型

| 类别 | 元素 | 场的算法 |
|---|---|---|
| 电荷分布 | 点电荷、电偶极子、线电荷、带电面、带电柱 | 点电荷软化叠加；偶极子用 `E = k[3(p·r̂)r̂−p]/r³`；柱外场等价于轴线线电荷 `λ = ρπr²` |
| 电流分布 | 线电流、电流环、面电流、柱电流、螺线管 | 毕奥–萨伐尔**解析段积分**：`B = I(sinα_b − sinα_a)/d · φ̂`，长直导线一次求值而不是离散 |
| 磁偶极子 | 磁偶极子 | `B = k[3(m·r̂)r̂−m]/r³` |
| 匀强区 | 匀强电场区、匀强磁场区 | 盒形区域 + 软边界（smoothstep） |

写法上有个关键决定：**长直导线用解析解**。原来把导线切成小段求和，是 O(段数) 的近似；换成闭式解后，
一个采样点对一根导线只算一次，于是"面电流 = 一排导线""柱电流 = 一圈导线""螺线管 = 一组环"这些
**由基本元件拼出来的元素**才有可能实时存在。

### 9.2 势：φ 与 A

```
φ(r) = Σ k q/r      E = −∇φ
A(r) = Σ k I ∫ dl/|r−r′|      B = ∇×A
```

按 `V` 在探针处切一个**垂直于视线**的平面，把它画成热图 + 等势线。

- 选这个平面是工程上的取巧：垂直于视线的平面在透视投影下是**均匀缩放**，所以一张 44×44 的位图可以用
  `drawImage` 精确贴上去，不需要逐格画多边形。既快又平滑。
- 归一化用**分位数**（φ 用 80 分位、A 用 80 分位），否则 `1/r` 的奇点会把整张图压成灰色。
- 切面跟着探针走，等于一台"场的显微镜"：飞到哪里，就在哪里采样。

A 的视图比 φ 更有信息量：它绕着电流打圈。在螺线管里你会看到 **轴线上 A ∝ ρ 从 0 开始增长，而 B 在轴线上最大**——
势和场不同向，这是课本上一句"B = ∇×A"很难传达的直觉。

### 9.3 实验室

标题页 → **场实验室**。左键把选中的元素放到准星处，`X` 删除，`[` `]` 调强度，`V` 看势。
场线与势在放置后立刻重算（去抖 90–150 ms）。内置五个示例：电偶极子、平行板、螺线管、直导线、四极场。

这是把原来那个"沿场线走、看到电荷标记"的构想**真正落地**的地方：
你不只是沿着别人给的场线走，你可以把源摆进去，看场线当场改写。

---

1. **关卡码 / 分享**：把实验室里摆好的源序列化成字符串，别人粘贴即可打开同一片场。
2. **电磁感应门**：只认 `dΦ/dt` 的门，逼玩家在变化磁场里穿梭。
3. **波与辐射**：接近 c 时的切伦科夫锥、同步辐射拖尾，作为高 β 的视觉奖励。
4. **多人竞速**：同一个场区，比谁先以正确速度穿过三道门。
5. **D 与 H**：只有当关卡进入介质（极化/磁化）时才引入 D、H，否则它们永远是 E、B 的常数倍。
