OpenCircuit EDA

          
Version v2.1.0 · Schema v2 · Author: Etherealnymph

        

      

      

        核心功能：Spectre / SPICE / Verilog / VHDL 网表解析与图形化、正交自动布线、MNA 直流/瞬态/交流频域仿真、示波器与频谱仪、PDK 工艺库与子电路层次化设计。
      

      

        
v2.1.0 更新日志：

        
    
          
  • 文件支持文件与文件夹重命名
    • 
          
  • 放置元件免参数弹窗，支持鼠标跟随预览、左键连续放置与快捷键放置
    • 
          
  • 放置电源默认为独立空白端口，新增红空圆 / 实心黑圆 / 空黑圆节点放置
    • 
          
  • 支持单击/Ctrl+多选电线及 Delete 删除连线
    • 
          
  • 新增「操作」菜单栏：顺/逆时针旋转、水平/垂直对称、复制粘贴及快捷键
