LL-8 / ACCUMULATOR MACHINE

给电路一段程序。

16 位指令，8 位数据，256 字节 RAM。每个时钟上升沿执行一条指令；算术结果保留低 8 位。

指令集与布线说明
指令含义 / 操作码
MOVI nA ← n / 1
ADDI / SUBI nA ← A ± n / 2、3
ANDI / XORI nA ← A & n / A ⊕ n / 4、5
JMP addr跳转 / 6
JZ addrA=0 时跳转 / 7
STORE / LOAD addr保存 / 读取 A / 8、9
HALT保持 PC / 15

指令高 4 位是操作码，低 8 位是立即数；中间 4 位保留。支持标签、十进制、0x 十六进制、0b 二进制和分号注释。未使用 ROM 地址视为 HALT。未定义操作码不写寄存器，PC 继续前进。上限 256 条指令。

PC→ROM→DECODE；DECODE 控制 ALU、MUX、REG、RAM 和 PC。跳转条件来自 REG.Q 的 ZERO 检测，不能接 ALU.ZERO。
