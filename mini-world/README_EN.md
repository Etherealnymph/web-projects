## Overview

Mini World is a no-build Three.js sandbox. Walk through Beijing, Washington, Tokyo, the Forbidden City and more, build at 0.25–1 m scale, and take vehicles, trains, drones and carriers out for a run — all in one static page.

## Features

- Explore / build / fight with walkable multi-storey buildings, 20 cm staircases and per-floor elevators.
- Ten worlds including Beijing, Washington, Tokyo, the Forbidden City, Chang'an by night, UESTC campus and a global expedition mode.
- Fine construction at 0.25 / 0.5 / 1 m, city props, gardens, markets and a harbour fish market.
- Vehicles, loop trains, drone swarms, anti-air interception and carrier deck take-off.
- AI dialogue building, world notes and a guestbook, weather and seasons, soldier squads and naval combat.
- Import/export for worlds, weapons and characters; only local Three.js r150, no build step.

## Project structure

```text
mini-world/
├─ index.html
├─ css/ / js/                 # engine, world, player, combat, UI
├─ assets/                    # textures, menu art, screenshots source
├─ characters/ / weapons/     # model definitions
├─ worlds/                    # ten world definitions
├─ prompt/ / skills/          # AI builder prompts and rules
├─ tests/                     # node:test + model gallery
├─ vendor/three.min.js
├─ serve.py                   # tiny local server
├─ DATA_SOURCES.md
└─ docs/screenshot.png
```
