# 体悟集前端升级说明 · 2026-11

本轮保留原生 ES Module、纸墨配色、GitHub Pages 部署方式和现有权限模型。数据库先升级，再更新前端：具体 SQL 顺序见 [Supabase 升级指南](./SUPABASE_UPGRADE_2026-11.md)。

## 主要改动

### 加载、列表和搜索

- 首页、登录、编辑器、文章、个人页、后台、私信按路由加载。入口不再提前加载全部页面。
- 模块、收藏、搜索和个人文章列表每页 12 条；“加载更多”只追加新卡片，重复项按内容 ID 去重。
- 搜索、筛选和分页使用请求序号；较早发出的慢请求不能覆盖较新的结果。离开页面会取消防抖、清理监听器，并隔离旧页面的异步结果。
- 作者/标签候选使用独立 `contents.facets()`，不再为筛选框拉取完整正文；点赞榜通过 `sort: 'like'` 查询，避免只在热榜的前 20 名里重新排序。
- 列表最多并行解析 4 张封面；不为尚未打开的文章预先解析全部视频、音频和文件。
- 个人页计数来自 `contents.summary()` 的授权范围内聚合，避免把当前一页的点赞误当成累计点赞。

静态依赖检查显示，入口立即需要的 JavaScript 从原来 23 个模块、约 283 kB 降至 9 个模块、约 100 kB（未压缩）。这只衡量静态导入图，不包括实际打开的页面、动态后端、网络缓存和压缩；不能把这一数字解释成实测加载时间的同等提升。

### 阅读

- 文章根据一级到三级标题生成可折叠目录；目录跳转保持当前 SPA 路由。
- 顶部阅读进度、估计阅读时间、专注模式、复制链接、Markdown 正文导出。
- 正文阅读宽度限制为约 74 个字符宽，移动端保持单列。
- 修复详情附件点击后出现两层灯箱、私有/本地附件灯箱使用原始地址、详情加载后评论框抢占焦点、问答收起时摘要同时消失等问题。
- 灯箱改为可键盘关闭、管理焦点的弹窗；视频控件点击不再误关闭整个灯箱。

Markdown 导出包含正文及其中的媒体引用，不打包二进制附件，也不是完整数据库备份。

### 编辑和草稿

- 正文、标题、标签、模块、可见范围及媒体引用自动保存到当前浏览器；按后端、用户、文章区分草稿。
- 再次打开编辑页时可恢复或删除未提交草稿。草稿是本地恢复机制，不改变云端内容的发布状态或权限。
- 新文章按 `⌘ / Ctrl + S` 保存为草稿；已发布文章使用该快捷键保存修改。明确点击“发布”才会发布新文章。
- 上传或录音期间阻止提交不完整内容；保存过程中冻结表单，避免保存请求发出后继续输入的文字被丢失。
- 页面退出会停止录音、关闭麦克风轨道、取消预览任务。隐藏的预览不再随每次键入重新解析。
- 修复小编辑器存在两个预览节点、表情上传同时触发两套上传处理等问题。

浏览器本地空间不足或不可用时会显示保存失败，不能把此时的草稿当作已持久保存。清理浏览器数据仍会清除本地草稿。

### 私信与键盘操作

- 私信先展示最新 50 条，支持向上加载更早消息和手动刷新；加载旧消息时尽量保持阅读位置。
- 切换会话期间尚未返回的请求不能覆盖新会话；发送完成后不会清空另一个会话的输入框。
- 中文输入法确认候选词时的 Enter 不再被当作发送消息。
- `⌘ / Ctrl + K` 打开快速前往面板；`/` 聚焦搜索，`N` 新建文章。浏览器已有的 Ctrl/⌘/Alt 组合键得到保留。
- 为表单补齐标签、为互动按钮提供选中状态、为菜单提供方向键操作、为模态框提供 Tab 焦点约束与关闭后的焦点返回。
- 页面初次绘制前读取已选主题，减少暗色模式的浅色闪屏；尊重系统“减少动态效果”设置。

## 自动化检查

在仓库根目录使用 Node.js 22 或更新版本运行：

```bash
node --test insight-space/tests/frontend.test.mjs
```

测试覆盖路由解析、离开页面的任务取消、媒体并发上限、本地草稿隔离/异常处理、Markdown 输入、搜索竞态、分页与去重。无额外 npm 依赖。

## 独立 UI 验收页面

```bash
python3 -m http.server 8123
```

打开 `http://127.0.0.1:8123/insight-space/tests/ui-fixture.html`。

此页面明确标为 **Synthetic fixture / 合成数据测试**，使用真实视图模块与独立的内存 API；包含 32 篇文章、2 条评论和 120 条私信。它没有真实账号、密码或用户记录；页面 CSP 禁止网络连接，不连接 Supabase，文件上传入口也明确拒绝真实上传。刷新后内存内容重置，测试编辑草稿单独使用 `synthetic-fixture` 命名空间。

建议依次检查：

1. 首页和日记卡片；在模块筛选里选择“全部模块”，加载第二页，确认卡片没有重复。
2. 搜索“合成记录”，快速切换筛选，确认最终结果对应当前筛选。
3. 打开“阅读示例”，测试目录、阅读进度、专注模式、Markdown 下载、图片弹窗与 Esc。
4. 新建文章，键入内容后切走，再回来恢复草稿；用快捷键保存，确认显示“草稿”状态。
5. 私信先看到最新消息，点击“加载更早的消息”两次能看到全部 120 条。
6. 在窄屏和暗色主题下查看排版；仅用 Tab、方向键、Enter 和 Esc 操作弹窗。

合成 UI 验收不替代真实 Supabase 的 RLS、上传、登录和迁移验证。部署时可以不发布 `tests/` 目录。
