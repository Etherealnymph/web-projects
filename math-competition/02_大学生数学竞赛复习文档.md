## 一、先搞清楚考什么

### 1.1 赛制

| 项目 | 非数学类 | 数学类 |
|:--|:--|:--|
| 初赛 | 每年 11 月，2.5 小时，5 道大题（每题 20 分，共 100 分） | 同时间段，6 道大题 |
| 决赛 | 次年 3—4 月，3 小时，题型更综合 | 分数学分析、高等代数、解析几何等 |
| 内容 | 高等数学（不含级数的深水区也常考） | 数学分析 + 高等代数 + 解析几何 |
| 特点 | 没有选择题，全部要写过程；一题 20 分，一步错损失大 | 证明题比例更高 |

**关键差异**：竞赛不是考研。考研重"算得对"，竞赛重"想得到"。同一道题，往往需要先构造、再估计，最后才计算。

### 1.2 命题风格（近十年）

1. **极限与不等式结合**：数列极限 + 夹逼 + 定积分定义，几乎每届都有。
2. **积分不等式**：证明 $\int f^2 \ge \cdots$ 一类，方法是配方、Cauchy、二重积分化。
3. **多元积分**：二重/三重积分的对称性、换元、估值；曲线曲面积分必考 Green/Gauss。
4. **级数**：正项级数判敛、交错级数、幂级数求和、函数项级数一致收敛。
5. **微分方程**：一阶特殊类型 + 二阶变系数 + 由解反求方程。
6. **函数方程**：$f(x+y)=f(x)+f(y)$ 型、$f(ax)=bf(x)$ 型，配合连续性/单调性。
7. **证明恒为零/恒为常数**：中值定理 + 最大值原理。

### 1.3 评分逻辑

- 20 分一题，通常按"关键步骤"给分：构造出辅助函数、写出正确的估计式，就能拿一半。
- **不会做也要写**：写出题目的等价变形、特殊情形、能推出的显然结论，都可能得分。
- 结论错误但过程合理，仍可能得 10 分以上；结论正确但跳步，可能只得 10 分。

## 三、板块精讲

### 3.1 极限与连续

#### 核心结论

- **单调有界准则**：单调递增且有上界 ⇒ 收敛。
- **压缩映射**：若 $|x_{n+1}-a|\le k|x_n-a|$（$0<k<1$），则 $x_n\to a$，且 $|x_n-a|\le k^n|x_0-a|$。
- **Stolz 定理**：$\{y_n\}$ 严格递增趋于 $+\infty$，若 $\lim \frac{x_{n+1}-x_n}{y_{n+1}-y_n}=L$，则 $\lim\frac{x_n}{y_n}=L$。
- **定积分定义**：$\lim\limits_{n\to\infty}\frac1n\sum\limits_{i=1}^{n}f\left(\frac{i}{n}\right)=\int_0^1 f(x)\,dx$。
- **夹逼**：$a_n\le b_n\le c_n$ 且 $a_n,c_n\to L$。
- **等价无穷小**：$x\to0$ 时 $\sin x\sim x$，$\ln(1+x)\sim x$，$e^x-1\sim x$，$1-\cos x\sim \frac{x^2}{2}$，$(1+x)^\alpha-1\sim\alpha x$，$\tan x-x\sim\frac{x^3}{3}$。

#### 题型与对应题目

| 题型 | 关键动作 | 题目 |
|:--|:--|:--|
| 定积分定义求和式极限 | 把和式凑成 $\frac1n\sum f(\frac in)$ | [P001](01_题目全集.md#p001)、[P048](01_题目全集.md#p048) |
| 递推数列 | 先证有界，再证单调；或先求极限再证存在 | [P013](01_题目全集.md#p013)、[P020](01_题目全集.md#p020) |
| 压缩型递推 | $|x_{n+1}-x_n|\le q|x_n-x_{n-1}|$ | [P020](01_题目全集.md#p020)、[P008](01_题目全集.md#p008) |
| 与积分结合 | 分部积分/中值定理把积分化成数列 | [P054](01_题目全集.md#p054)、[P179](01_题目全集.md#p179) |
| 二元极限、方向 | 先沿特殊路径否定，再用极坐标/夹逼肯定 | [P181](01_题目全集.md#p181) |

#### 易错点

1. **单调性方向证反**：要证递增，必须 $x_{n+1}-x_n\ge0$ 对所有 $n$ 成立，不能只算前两项。
2. **先设极限再求**：只证明"若极限存在则为 $A$"，没证存在性，最多拿一半分。
3. **Stolz 用错**：分母必须严格单调趋于 $+\infty$；$\frac{0}{0}$ 型不能直接用。
4. **夹逼的界要同阶**：上下界必须收敛到同一个值，否则无效。

### 3.2 一元微分与中值定理

#### 核心结论

- **罗尔**：$f\in C[a,b]$，$(a,b)$ 可导，$f(a)=f(b)$ ⇒ $\exists\xi$，$f'(\xi)=0$。
- **拉格朗日**：$f(b)-f(a)=f'(\xi)(b-a)$。
- **柯西**：$\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$。
- **泰勒**：$f(x)=\sum\limits_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$。
- **导数定义**：$f'(a)=\lim\limits_{h\to0}\frac{f(a+h)-f(a)}{h}$，判可导先算左右差商。

#### 辅助函数构造口诀

| 要证的式子 | 构造 |
|:--|:--|
| $f'(\xi)+kf(\xi)=0$ | $F=e^{kx}f$ |
| $f'(\xi)g(\xi)-f(\xi)g'(\xi)=0$ | $F=\dfrac{f}{g}$ |
| $\xi f'(\xi)+kf(\xi)=0$ | $F=x^k f$ |
| $f'(\xi)=\dfrac{f(\xi)-f(a)}{b-a}$ | $F(x)=f(x)-\dfrac{f(b)-f(a)}{b-a}(x-a)$ |
| $f''(\xi)=0$ | 对 $f'$ 用罗尔 |
| $\xi=f(\xi)$ 型 | $F=f(x)-x$ |

#### 题型与对应题目

| 题型 | 题目 |
|:--|:--|
| 乘积可导的充要条件（导数定义硬算） | [P003](01_题目全集.md#p003)、[P004](01_题目全集.md#p004) |
| 两次拉格朗日证凸性（弦在曲线上方） | [P007](01_题目全集.md#p007) |
| 用最大值原理证 $f\equiv0$ | [P009](01_题目全集.md#p009)、[P010](01_题目全集.md#p010)、[P011](01_题目全集.md#p011)、[P012](01_题目全集.md#p012) |
| 构造 $f^2+f'^2$ 取内部最大值 | [P012](01_题目全集.md#p012) |
| 罗尔定理证驻点存在 | [P014](01_题目全集.md#p014)、[P170](01_题目全集.md#p170) |
| 中值定理 + 介值定理证导数值可达 | [P174](01_题目全集.md#p174) |

#### 易错点

1. **中值点位置**：结论是 $\xi\in(a,b)$（开区间），构造的辅助函数必须在闭区间连续、开区间可导。
2. **多次使用中值定理**：第二次用要在新的小区间上，且要说明区间包含关系。
3. **只证存在不证唯一**：若题目要求"唯一"，还需单调性。
4. **泰勒展开点选错**：通常在最值点或已知导数值的点展开。

### 3.3 一元积分与积分不等式

#### 核心结论

- **积分中值**：$f\in C[a,b]$ ⇒ $\exists\xi$，$\int_a^b f=f(\xi)(b-a)$；第一中值定理：$\int_a^b fg=f(\xi)\int_a^b g$（$g$ 不变号）。
- **Cauchy–Schwarz（积分型）**：$\left(\int_a^b fg\right)^2\le\int_a^b f^2\int_a^b g^2$。
- **Jensen**：$\varphi$ 凸，则 $\varphi\left(\frac{1}{b-a}\int_a^b f\right)\le\frac{1}{b-a}\int_a^b\varphi(f)$。
- **分部积分**：$\int_a^b u\,dv=uv\big|_a^b-\int_a^b v\,du$。
- **变限积分求导**：$\dfrac{d}{dx}\int_{a(x)}^{b(x)}f(t)\,dt=f(b(x))b'(x)-f(a(x))a'(x)$。

#### 积分不等式的五种武器

1. **配方法**：把被积式写成完全平方，如 $\int_0^1\left(f(t)-\sqrt{t}+t\right)^2dt\ge0$ → [P015](01_题目全集.md#p015)。
2. **二重积分法**：把 $\left(\int f\right)^2$ 或 $\int f\int g$ 写成 $\iint$，再用对称性/排序 → [P067](01_题目全集.md#p067)、[P068](01_题目全集.md#p068)、[P069](01_题目全集.md#p069)。
3. **Cauchy–Schwarz**：出现平方和、根号时优先 → [P100](01_题目全集.md#p100)、[P208](01_题目全集.md#p208)。
4. **单调性/最值**：构造 $F(x)=\int_a^x f$，证 $F'\ge0$ → [P017](01_题目全集.md#p017)、[P024](01_题目全集.md#p024)。
5. **Jensen/凸性**：出现 $\ln$、$e^x$、乘积时 → [P207](01_题目全集.md#p207)。

#### 反常积分

| 类型 | 判据 |
|:--|:--|
| $\int_a^{+\infty}\frac{dx}{x^p}$ | $p>1$ 收敛 |
| $\int_0^1\frac{dx}{x^p}$ | $p<1$ 收敛 |
| $\int_0^{+\infty}\frac{\sin x}{x^p}dx$ | $0<p<2$ 收敛（Dirichlet） |
| $\int_0^{+\infty}\sin x^2\,dx$ | 收敛（换元 + Dirichlet） |

对应题目：[P024](01_题目全集.md#p024)（$\sin^p x\cos^q x$ 的敛散性）、[P128](01_题目全集.md#p128)（$\int_0^\infty\sin x^2$）。

#### 易错点

1. **被积函数在积分区间内无界**：先找奇点，分段处理。
2. **换元后忘记改上下限**（定积分换元必须换限，且要求换元单调）。
3. **级数与积分混用**：逐项积分需要一致收敛或正项（Levi 定理）。
4. **等号条件**：Cauchy 取等要写清 $f$ 与 $g$ 线性相关。

### 3.4 多元微分与空间解析几何

#### 核心结论

- **切平面**：曲面 $F(x,y,z)=0$ 在 $P_0$ 的切平面为
  $$F_x(P_0)(x-x_0)+F_y(P_0)(y-y_0)+F_z(P_0)(z-z_0)=0.$$
- **法向量**：$\mathbf n=(F_x,F_y,F_z)\big|_{P_0}$；显式 $z=f(x,y)$ 时 $\mathbf n=(-f_x,-f_y,1)$。
- **方向导数**：$\dfrac{\partial f}{\partial \mathbf l}=\nabla f\cdot \mathbf l^0$，$\mathbf l^0$ 是单位向量。
- **极值必要条件**：内部极值点处 $\nabla f=0$；条件极值用 Lagrange 乘数法 $\nabla f=\lambda\nabla g$。
- **混合积**：$(\mathbf a\times\mathbf b)\cdot\mathbf c=\begin{vmatrix}a_x&a_y&a_z\\b_x&b_y&b_z\\c_x&c_y&c_z\end{vmatrix}$。

#### 题型与对应题目

| 题型 | 题目 |
|:--|:--|
| 切平面垂直于坐标面 → 法向量某分量为 0 | [P061](01_题目全集.md#p061) |
| 曲面上动点的方向导数为零 | [P181](01_题目全集.md#p181) |
| Lagrange 恒等式（混合积） | [P077](01_题目全集.md#p077) |
| 单位向量与和向量极限 | [P078](01_题目全集.md#p078) |
| 曲面上的最值 → 转化为边界问题 | [P079](01_题目全集.md#p079) |
| 由偏导数定义求 $f_x,f_y$ | [P168](01_题目全集.md#p168) |
| 二阶偏微分方程降阶 | [P202](01_题目全集.md#p202) |

#### 易错点

1. **方向导数用单位向量**：题目给的方向向量若非单位，要先单位化。
2. **切平面 vs 法平面**：曲面给切平面，曲线给法平面，别搞混。
3. **隐函数求导**：$F_z\ne0$ 才能解出 $z=z(x,y)$。

### 3.5 重积分

#### 核心结论

- **极坐标**：$dxdy=r\,dr\,d\theta$；**柱坐标**：$r\,dr\,d\theta\,dz$；**球坐标**：$\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$。
- **对称性**：区域关于 $x=0$ 对称时，被积函数关于 $x$ 为奇函数则积分为 0。
- **轮换对称**：区域在 $x,y,z$ 轮换下不变时，$\iiint x^2=\iiint y^2=\iiint z^2=\frac13\iiint(x^2+y^2+z^2)$。
- **交换次序**：$\int_a^b dx\int_{a}^{x}f(x,y)dy=\int_a^b dy\int_{y}^{b}f(x,y)dx$。
- **估值**：$m\cdot S\le\iint_D f\le M\cdot S$（$S$ 为面积），$m,M$ 为 $f$ 在 $D$ 上的最值。

#### 二重积分的四条主路

1. **直接化成累次积分**：先画区域，再定限（X 型或 Y 型）。
2. **极坐标**：区域含 $x^2+y^2$、圆、扇形时优先；注意 $r$ 的限由边界方程解出。
3. **换元**：广义极坐标 $x=ar\cos\theta,y=br\sin\theta$（雅可比 $abr$）；线性变换 $x=u+v,y=u-v$（雅可比 $|J|=2$）。
4. **对称性 + 分域去绝对值**：含 $|x-y|$、$|xy|$ 时按零点分域。

#### 易错点

1. **雅可比漏乘**：极坐标的 $r$、球坐标的 $\rho^2\sin\varphi$ 一定不能丢。
2. **球坐标的 $\varphi$ 范围**：从 $z$ 轴正向量起，$0\le\varphi\le\pi$；与柱坐标的 $\varphi$（与 $x$ 轴夹角）不同。
3. **区域分块**：被积函数含绝对值、或区域边界分段时，必须分块积分。
4. **先二后一 vs 先一后二**：截面形状简单时用"先二后一"。

### 3.6 曲线积分与曲面积分

#### 核心结论

- **第一型曲线积分**：$\int_L f\,ds=\int_\alpha^\beta f(x(t),y(t))\sqrt{x'^2+y'^2}\,dt$。
- **第二型曲线积分**：$\int_L Pdx+Qdy$，方向敏感；**Green 公式**：$\oint_{\partial D}Pdx+Qdy=\iint_D(Q_x-P_y)\,dxdy$（$L$ 取正向）。
- **第一型曲面积分**：$\iint_\Sigma f\,dS=\iint_D f(x,y,z(x,y))\sqrt{1+z_x^2+z_y^2}\,dxdy$。
- **第二型曲面积分**：$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy=\iint_\Sigma (P\cos\alpha+Q\cos\beta+R\cos\gamma)\,dS$，方向为"外侧"。
- **Gauss 公式**：$\oiint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy=\iiint_\Omega(P_x+Q_y+R_z)\,dV$。
- **Stokes 公式**：$\oint_\Gamma Pdx+Qdy+Rdz=\iint_\Sigma\begin{vmatrix}dydz&dzdx&dxdy\\ \partial_x&\partial_y&\partial_z\\ P&Q&R\end{vmatrix}$。

#### 解题套路

| 情形 | 做法 |
|:--|:--|
| 闭合曲面 + 高斯公式 | 直接化三重积分；**不闭合就补面**，注意补面的方向 |
| 曲面有奇点（如 $1/r^2$） | 挖小球，用高斯公式在挖空区域上 |
| 第二型 → 第一型 | 乘方向余弦 $\cos\alpha,\cos\beta,\cos\gamma$，或用 $\mathbf n\,dS$ |
| 第一型曲面含 $\frac{1}{\rho}$ | 球坐标 + 球带面积 / 立体角 |
| 投影有重叠 | 分片投影，或改用参数方程 |
| 曲线积分与路径无关 | 验证 $Q_x=P_y$，选折线路径 |

| 题型 | 题目 |
|:--|:--|

### 3.7 无穷级数（本课程重点，63 题）

#### 正项级数判敛

| 方法 | 使用信号 |
|:--|:--|
| 比较判别法（极限形式） | 通项与 $\frac{1}{n^p}$ 同阶 |
| 比值/根值 | 含 $n!$、$a^n$、$n^n$ |
| Raabe 判别 | 比值极限为 1 时 |
| 积分判别 | 通项为单调递减的正值函数 |
| 对数判别 | $\lim\frac{\ln u_n}{\ln n}=q$，$q<-1$ 收敛 |
| Kummer | 一般化的比较 |

#### 交错与任意项

- **Leibniz**：$u_n$ 单调递减趋于 0 ⇒ $\sum(-1)^nu_n$ 收敛。
- **Dirichlet**：$\sum a_n$ 部分和有界，$b_n$ 单调趋于 0 ⇒ $\sum a_nb_n$ 收敛。
- **Abel**：$\sum a_n$ 收敛，$b_n$ 单调有界 ⇒ $\sum a_nb_n$ 收敛。
- **绝对收敛 ⇒ 收敛**；条件收敛的级数可重排改变和（Riemann 定理）。

#### 幂级数

- 收敛半径 $R=\lim\left|\frac{a_n}{a_{n+1}}\right|$ 或 $\frac{1}{\lim\sqrt[n]{|a_n|}}$。
- 逐项求导/积分不改变收敛半径，但端点可能变。
- 求和套路：先求导化成几何级数 → 求和 → 再积分回去。

#### 函数项级数

- **一致收敛判别**：Weierstrass $M$ 判别、Dirichlet、Abel。
- **逐项积分**：一致收敛即可；正项级数可用 Levi（单调收敛）。
- **逐项求导**：需 $\sum f_n'$ 一致收敛且 $\sum f_n$ 在某点收敛。

| $\sum\frac{1}{n^{1+1/n}}$、$\sum\frac{\sqrt[n]{n}-1}{n}$ | [P107](01_题目全集.md#p107)、[P108](01_题目全集.md#p108) |

#### 易错点

1. **比较判别法的极限形式**：极限为 0 或 $+\infty$ 时的结论要分清。
2. **Leibniz 的单调性**：只证 $u_n\to0$ 不够，必须单调递减。
3. **端点单独讨论**：收敛半径内必收敛，端点要代回原级数判。
4. **绝对收敛与条件收敛**：$\sum(-1)^n\frac{1}{n^p}$ 在 $0<p\le1$ 条件收敛，$p>1$ 绝对收敛。
5. **逐项积分**：函数项级数一般不能随便逐项积分，必须一致收敛（或正项）。

### 3.8 微分方程（16 题）

#### 一阶方程的类型识别

| 形式 | 方法 |
|:--|:--|
| $y'=f(x)g(y)$ | 分离变量 |
| $y'=f\left(\frac{y}{x}\right)$ | 令 $u=y/x$ |
| $y'+P(x)y=Q(x)$ | 积分因子 $e^{\int P}$ |
| $y'+P(x)y=Q(x)y^n$ | Bernoulli，令 $z=y^{1-n}$ |
| $Pdx+Qdy=0$ 且 $P_y=Q_x$ | 全微分，求原函数 |
| 一阶隐式 $F(x,y,y')=0$ | 令 $y'=p$ 参数化 |

#### 二阶方程

- **常系数齐次**：特征根 $r_1,r_2$；重根乘 $x$；共轭复根给 $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$。
- **常系数非齐次**：待定系数法（$f=e^{\lambda x}P_m(x)$ 型、$e^{\lambda x}(A\cos\omega x+B\sin\omega x)$ 型）。
- **变系数**：降阶（已知一个特解 $y_1$，令 $y=y_1\int u$）、Euler 方程（$x=e^t$）、观察法。
- **由解反求方程**：把已知解代入，比较系数 → [P028](01_题目全集.md#p028)、[P042](01_题目全集.md#p042)。
- **有界解/周期解**：先求通解，再用有界性/周期性定常数 → [P040](01_题目全集.md#p040)、[P041](01_题目全集.md#p041)。

#### 题型与对应题目

| 题型 | 题目 |
|:--|:--|
| 8 个典型一阶/二阶通解 | [P029](01_题目全集.md#p029)–[P036](01_题目全集.md#p036) |
| 代换 $u=y-xy'$ | [P037](01_题目全集.md#p037) |
| 分段右端求连续解 | [P038](01_题目全集.md#p038) |
| 非齐次特解 + 有界性 | [P040](01_题目全集.md#p040)、[P041](01_题目全集.md#p041) |
| 由 $e^{mx}$ 型特解定参数 | [P042](01_题目全集.md#p042) |
| 两次换元化齐次 | [P043](01_题目全集.md#p043) |
| 积分方程 → 微分方程 | [P063](01_题目全集.md#p063)、[P071](01_题目全集.md#p071)、[P184](01_题目全集.md#p184) |

#### 易错点

1. **丢解**：分离变量时除以 $g(y)$，要单独检查 $g(y)=0$ 的解。
2. **特解形式**：$\lambda$ 是特征根时要乘 $x^k$。
3. **任意常数个数**：二阶方程通解含两个独立常数，少了就错。
4. **积分方程求导**：先确认被积函数连续，再求导。

### 3.9 代数、多项式与不等式

- **多项式根与导数根**：$f$ 的根与 $f'$ 的根交错（Rolle）；$\sum\frac{1}{x_i-y_j}$ 型可构造对数导数 → [P201](01_题目全集.md#p201)。
- **对称矩阵计数**：按迹、秩分类递推 → [P151](01_题目全集.md#p151)。
- **混合积恒等式**：$(\mathbf a\times\mathbf b)\cdot(\mathbf c\times\mathbf d)=(\mathbf a\cdot\mathbf c)(\mathbf b\cdot\mathbf d)-(\mathbf a\cdot\mathbf d)(\mathbf b\cdot\mathbf c)$ → [P077](01_题目全集.md#p077)。
- **Jensen 不等式**：凸函数 $g$ 满足 $g\left(\frac{\sum x_i}{n}\right)\le\frac{\sum g(x_i)}{n}$，取等当且仅当 $x_i$ 全相等 → [P207](01_题目全集.md#p207)。
- **Cauchy–Schwarz**：$(\sum a_ib_i)^2\le\sum a_i^2\sum b_i^2$，积分形式同理 → [P100](01_题目全集.md#p100)、[P208](01_题目全集.md#p208)。

## 四、通用解题武器库

### 4.1 看到这些条件，想到这些

| 条件 | 第一反应 |
|:--|:--|
| $f$ 连续 + 积分不等式 | 构造变限积分 $F(x)=\int_a^x f$，证 $F'\ge0$ |
| $f(a)=f(b)$ | 罗尔定理 |

| 出现 $e^{\lambda x}f+f'$ | 构造 $e^{\lambda x}f$ |
| 出现 $\frac{f'}{f}$ | 构造 $\ln f$ |
| 出现 $\int f^2$ 与 $\int f$ | Cauchy 或配方 |
| 对称区域 | 奇偶性、轮换对称 |
| 闭合曲面 | Gauss 公式 |
| 不闭合曲面 | 补面 |
| 曲线积分路径无关 | 找原函数 |
| 级数 + $n$ 在指数上 | 根值判别 |
| 级数 + $n!$ | 比值判别 |
| 交错级数 | Leibniz + 单调性 |
| 幂级数求和 | 逐项求导/积分 |
| 递推数列 | 单调有界 / 压缩 |
| 证明恒为零 | 最大值原理 + 任意小 |

### 4.2 三个万能套路

1. **"任意小"套路**：要证 $f\equiv0$，先证 $|f(x)|\le\varepsilon$ 对任意 $\varepsilon>0$ 成立。
2. **"二重积分"套路**：一元积分不等式 → 写成 $\iint$ → 用对称性/排序/配方。
3. **"特殊化"套路**：先取特殊函数（常数、$x$、$\sin$）验证，再推广；或先证弱结论（有界），再证强结论（收敛）。

- [ ] 积分区域画了吗？边界交点算对了吗？
- [ ] 雅可比乘了吗？
- [ ] 曲面积分的方向对吗？
- [ ] 中值定理的区间是开区间吗？

- [ ] 微分方程的任意常数个数对吗？

## 六、公式速查

### 6.1 极限与等价无穷小

$$\sin x\sim x,\quad \tan x\sim x,\quad \arcsin x\sim x,\quad \arctan x\sim x,$$
$$e^x-1\sim x,\quad \ln(1+x)\sim x,\quad 1-\cos x\sim\frac{x^2}{2},\quad (1+x)^\alpha-1\sim\alpha x,$$
$$x-\sin x\sim\frac{x^3}{6},\quad \tan x-x\sim\frac{x^3}{3},\quad \ln(1+x)-x\sim-\frac{x^2}{2}.$$

### 6.2 泰勒展开

$$e^x=1+x+\frac{x^2}{2!}+\cdots+\frac{x^n}{n!}+o(x^n),$$
$$\sin x=x-\frac{x^3}{3!}+\frac{x^5}{5!}-\cdots,\qquad \cos x=1-\frac{x^2}{2!}+\frac{x^4}{4!}-\cdots,$$
$$\ln(1+x)=x-\frac{x^2}{2}+\frac{x^3}{3}-\cdots,\qquad (1+x)^\alpha=1+\alpha x+\frac{\alpha(\alpha-1)}{2}x^2+\cdots.$$

### 6.3 积分公式

$$\int_0^{\pi/2}\sin^n x\,dx=\int_0^{\pi/2}\cos^n x\,dx=\begin{cases}\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2},&n\text{ 偶}\\[2mm]\dfrac{(n-1)!!}{n!!},&n\text{ 奇}\end{cases}$$
$$\int_0^{+\infty}e^{-x^2}dx=\frac{\sqrt\pi}{2},\qquad \int_0^{+\infty}\frac{\sin x}{x}dx=\frac{\pi}{2},\qquad \int_0^{+\infty}\frac{dx}{1+x^2}=\frac{\pi}{2}.$$
$$\iint_{x^2+y^2\le R^2}f\,dxdy=\int_0^{2\pi}d\theta\int_0^R f(r\cos\theta,r\sin\theta)\,r\,dr.$$

### 6.4 曲面与曲线

$$\iint_\Sigma f\,dS=\iint_D f\sqrt{1+z_x^2+z_y^2}\,dxdy,$$
$$dS=\frac{|\mathbf r_u\times\mathbf r_v|}{}\,\text{（参数方程时取模）},\qquad \mathbf n\,dS=(F_x,F_y,F_z)\,dxdy\ \text{（隐式曲面，投影到 }xOy).$$

### 6.5 级数

$$\sum_{n=1}^\infty\frac{1}{n^p}\ \text{收敛}\iff p>1,\qquad \sum_{n=1}^\infty\frac{1}{n(\ln n)^p}\ \text{收敛}\iff p>1,$$
$$\frac{1}{1-x}=\sum_{n=0}^\infty x^n\ (|x|<1),\qquad e^x=\sum_{n=0}^\infty\frac{x^n}{n!},\qquad \ln(1+x)=\sum_{n=1}^\infty\frac{(-1)^{n-1}x^n}{n}\ (-1<x\le1).$$
$$\sum_{n=1}^\infty\frac{1}{n^2}=\frac{\pi^2}{6},\qquad \sum_{n=1}^\infty\frac{(-1)^{n-1}}{n}=\ln2,\qquad \sum_{n=0}^\infty\frac{1}{n!}=e.$$

### 6.6 常用不等式

$$2ab\le a^2+b^2,\qquad \frac{2}{\frac1a+\frac1b}\le\sqrt{ab}\le\frac{a+b}{2}\le\sqrt{\frac{a^2+b^2}{2}},$$
$$\left(\sum a_ib_i\right)^2\le\sum a_i^2\sum b_i^2,\qquad \left(\int f g\right)^2\le\int f^2\int g^2,$$
$$(1+x)^\alpha\ge1+\alpha x\ (x>-1,\ \alpha\ge1),\qquad \ln x\le x-1,\qquad e^x\ge1+x.$$

### 7.2 书写规范（拿过程分的关键）

4. **分类讨论写全**：$p>1$、$p=1$、$0<p<1$ 三档都写。
