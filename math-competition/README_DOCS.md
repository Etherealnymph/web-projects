1. 先看 `00` 了解照片顺序与拍摄场次；
2. 复习时按 `01` 的分区目录跳转，或在顶部"按专题速查"里按板块刷题；
3. 系统复习用 `02`，其中的 `P###` 链接可直接跳到 `01` 的对应题；
4. 手机上看 md 建议用 **Markdown 阅读器**（如 Markor、Obsidian、Typora），锚点跳转才生效。
