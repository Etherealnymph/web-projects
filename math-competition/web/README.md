# 题目放映（一题一屏）

把 `../01_题目全集.md` 的 **230 道题**做成**一题一屏**的全屏放映页，可直接当 PPT 用。

> 其中 22 题来自 `../docs/`：4 份模拟卷 PDF（卷一／四／五／六）与「全国赛非数学类·模拟检测卷第三套」的 18 张长图；
> 目录页（`M`）里这些都带「模拟卷」标识。

## 打开方式

双击 `index.html`（用 Chrome / Edge / Firefox 均可）。

- **必须保持 `index.html` 与 `vendor/` 文件夹在同一目录**（公式字体在 `vendor/katex/` 里）。
- 完全离线：不联网也能渲染公式（KaTeX 已随包内置）。
- 想看某一题，可在地址后加 `#p028` 这样的锚点，例如
  `index.html#p028`，可直接定位并分享。

## 快捷键

| 键 | 作用 |
|:--|:--|
| `→` `Space` | 下一题 |
| `←` | 上一题 |
| `↓` `↑` `PgDn` `PgUp` | 内容较长时先滚动，滚到底再翻页 |
| `Home` / `End` | 第一题 / 最后一题 |
| `F` | 全屏 / 退出全屏（也可用 F11） |
| `M` | **目录**：24 个分区一览（模拟卷一/三/四/五/六、模拟检测卷·第三套均有标识），点一行跳到该区第一题 |
| `O` | 题目总览（可按题号、关键字筛选，点卡片跳转） |
| `G` | 输入题号跳转（`28` 或 `P028`） |
| `T` | 展开本题的**评注 / 课堂板书 / 备注 / 原始照片** |
| `D` | 深色 / 浅色主题 |
| `+` `-` `0` | 放大 / 缩小当前题字号，`0` 复位 |
| `P` | 排版全部题目并调用打印（可「另存为 PDF」当讲义） |
| `!` | 全文公式自检（统计未识别公式数，正常为 0） |
| `Esc` | 关闭浮层 |
| `?` | 快捷键帮助 |

鼠标：底部按钮翻页；屏幕左右边缘可点击翻页；内容未溢出时滚轮也能翻页。
手机 / 平板：左右滑动翻页。

## 版式说明

- **一题一屏**：上方是题目（左侧红杠），有答案的题给出「答案」条，下面是「完整解答」。
- 顶栏左侧显示「分区号 · 分区名」（如 `23 · 模拟卷六（模拟测试六）`），右侧是题号徽标。
- 字号**自动适配**：内容少的题自动放大（投影友好），内容长的缩到 14.5px 为止，
  再长则出现「↕ 可滚动」提示，底部有渐隐提示，用 `↓`/滚轮继续看。
- 步骤小标题（`**一、上界.**` 这类）渲染成主题色小标题，便于快速抓结构。

## 重新生成

数据来自 `../01_题目全集.md`。改了 Markdown 之后，在 `math-competition/` 目录下运行：

```bash
python _work/build_web.py
```

会重新生成 `web/index.html`（并刷新 `web/vendor/katex/`）。
生成脚本依赖本机 VS Code 的 Marp 扩展里自带的 KaTeX 字体（路径写在脚本顶部 `KATEX_SRC`），
若换了机器，把该路径改成本地 `katex/dist` 即可。
