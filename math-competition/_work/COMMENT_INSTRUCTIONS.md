# 评注任务说明（大学生数学竞赛题目）

## 输入

`/sdcard/Download/DSH-GO/Image/work/chunk_NN.json`，字段：

- `chunk`：块号
- `items[]`：
  - `pid`：题目编号（唯一，输出时必须原样带回）
  - `label`：原题号
  - `statement`：题干（LaTeX）
  - `answer`：图中原有答案（可能为空）
  - `notebook_candidate`：从投影照片上抄下来的板书要点，**可能对应本题，也可能是同屏其他题或上一题的推导**，不要盲信

## 输出

写入 `/sdcard/Download/DSH-GO/Image/work/comment/NN.json`（NN 同 chunk 号），结构：

```json
{
  "chunk": 1,
  "items": [
    {"pid": 1, "commentary": "……", "solution_clean": "……"}
  ]
}
```

每个输入 item 必须有且只有一条输出，`pid` 一一对应，顺序一致。

## commentary 要求

面向准备大学生数学竞赛（非数学类为主，兼顾数学类）的学生，90~180 字，包含三层意思：

1. **考点**：这道题考的是什么板块的什么具体方法（如"积分中值定理 + 夹逼"、"Gauss 公式补面"、"Abel 变换"）。
2. **破题**：关键的一两步怎么想出来的，可以带关键式子（LaTeX 行内 `$...$`）。
3. **易错/推广**：最容易掉进去的坑，或可以记住的一般性结论。

写作风格：像老师批在题目旁边的批注，直给结论，不写"本题考察了……"，不写"综上所述"，不超过 3 句话。中文，数学式子用 LaTeX。

## solution_clean 要求

- 若 `notebook_candidate` 确实是在解这道题（符号、条件对得上）且推导无误：压缩成 4~10 行的要点解答，保留关键式子与中间结果，行内 LaTeX，不要逐步解释。
- 若候选对不上、残缺、或明显有错：输出空字符串 `""`（**不要**自己凭空写一份完整解答）。
- 若图中本来就有答案（`answer` 非空）而候选为空：也可以直接给 `""`，答案会单独显示。

## 硬性要求

- 不要编造题目的条件；不要改变题意。
- 输出必须是合法 JSON（转义正确），写完用 `read` 读回确认能解析、条数 = 输入条数。
- 完成后只回复一行：`chunk NN: 16 条，solution 保留 X 条`。
