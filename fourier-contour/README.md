### English

A two-way tool: feed it a Fourier parameter document and watch a pen trace the whole outline, or feed it an image and get back a readable, editable parameter document that reproduces every contour — including interior holes.

### 简体中文

一个双向工具：传入傅里叶系数参数文档，就能看到笔尖一笔画出整条轮廓；传入图片，则会把全部轮廓（含内部孔洞）做傅里叶展开，导出一份可读、可编辑、可版本管理的参数文档。
