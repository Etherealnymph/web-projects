## Overview

A two-way tool: feed it a Fourier parameter document and watch a pen trace the whole outline, or feed it an image and get back a readable, editable parameter document that reproduces every contour — including interior holes.

## Features

- Document → animation: play the classic rotating-circles animation, with multiple contours drawn by multiple chains at once.
- Image → document: extract every contour, including holes, Fourier-expand it and export an editable parameter document.
- Speed from 0.5 s to 60 s per turn, or 0.5×–20× presets; wheel zoom, drag pan and double-click reset.
- Keyboard shortcuts: Space, arrow keys; three prepared examples included.
- Zero dependencies, zero build, zero backend: double-click `index.html`.
