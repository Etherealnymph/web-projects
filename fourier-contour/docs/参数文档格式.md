# 参数文档格式说明

本工具用一份 **纯 JSON 文本**（下称「参数文档」）描述一个图像轮廓的傅里叶展开。
文档分三段：**图像说明 → 元信息 → 各项参数**。

- 想直接看例子：`examples/minimal-circle.json`（2 项，最短）、`examples/nested-rings.json`（多轮廓 + 内部孔洞）和 `examples/*.json`（完整示例）。
- 想在线试用：打开 `index.html` → 视图一，从「内置示例文档」下拉里选一个，改任意数字后点「应用文档并播放」。

文档有两种结构，解析器自动识别：

| 结构 | 何时使用 | 顶层字段 |
| --- | --- | --- |
| 单轮廓（version 1） | 只有一条闭合轮廓 | `terms` |
| **多轮廓（version 2）** | 有多条轮廓，或图形有内部孔洞 | `contours: [{ role, name, terms }]` |

---

## 1. 单轮廓文档

```jsonc
{
  "format": "fourier-contour",          // 格式标识（可选）
  "version": 1,                          // 版本号（可选）

  "description": "……图像说明……",          // ★ 开头必有的自然语言说明

  "meta": {                              // 元信息（可选，仅供展示与溯源）
    "name": "心形 heart",
    "source": "builtin:heart",           // 来源：builtin:xx / image:文件名 / handwritten
    "createdAt": "2026-01-01T00:00:00.000Z",
    "pointCount": 512,                   // 采样点数 N
    "termCount": 128,                    // 保留项数 K
    "droppedTerms": 384,                 // 被丢弃的项数
    "amplitudeCoverage": 0.999999,       // 振幅覆盖率（保留项的 Σamp² / 全部 Σamp²）
    "maxReconstructError": 2.4364,       // 截断后与原轮廓的最大偏差（单位与 unit 一致）
    "rmsReconstructError": 0.2511,
    "phaseUnit": "rad",                  // 相位单位：rad（默认）或 deg
    "sortedBy": "amplitude-desc",        // terms 的排序方式
    "origin": "top-left",                // 坐标原点：top-left 或 center
    "yAxis": "down",                     // y 轴方向
    "unit": "px",
    "coordinate": {                      // 轮廓的包围盒
      "width": 398.3, "height": 290.4,
      "minX": -199.1, "minY": -145.2, "maxX": 199.2, "maxY": 145.2,
      "canvasWidth": 512, "canvasHeight": 512
    },
    "notes": "p(t) = Σ amp·e^{i(2π·n·t + phase)}，t∈[0,1)。"
  },

  "terms": [                             // ★ 各项参数，每项一个圆
    { "n": 0,  "amp": 3.2041, "phase": 0 },
    { "n": 1,  "amp": 178.9,  "phase": -1.5708 },
    { "n": -1, "amp": 178.9,  "phase": 1.5708 }
  ]
}
```

## 2. 多轮廓文档（包含图像内部的孔洞）

一个图形往往不止一条轮廓：字母「O」有内孔、同心圆环有多层、logo 里可能有多个独立形状。
**提取到一条以上轮廓时，文档改用顶层 `contours` 数组**，每条轮廓各自带一组 `terms`：

```jsonc
{
  "format": "fourier-contour",
  "version": 2,
  "description": "由图像「示例图:target」提取轮廓生成：共提取 5 个轮廓（含 2 个内部孔洞）……",

  "meta": {
    "name": "示例图:target",
    "contourCount": 5,
    "outerCount": 3,
    "holeCount": 2,
    "termCount": 410,                    // 所有轮廓的项数之和
    "pointCount": 2560,
    "amplitudeCoverage": 0.999997,
    "termCountPolicy": "每个轮廓的项数 = K·√(该轮廓面积/最大轮廓面积)，下限 6 项",
    "coordinate": { "width": 250.0, "height": 250.0, "minX": 35.0, "minY": 35.0, "maxX": 285.0, "maxY": 285.0 },
    "contours": [                        // 每条轮廓的概要（可选，便于快速了解文档）
      { "index": 0, "role": "outer", "name": "外轮廓 1", "area": 48717.4,
        "pointCount": 512, "termCount": 160, "amplitudeCoverage": 0.999998,
        "maxReconstructError": 1.2, "rmsReconstructError": 0.08,
        "coordinate": { "width": 250.0, "height": 250.0 } },
      { "index": 1, "role": "hole",  "name": "内部孔洞 2", "area": 27455.1,
        "pointCount": 512, "termCount": 120, "amplitudeCoverage": 0.999991 }
    ]
  },

  "contours": [                          // ★ 每条轮廓一组 terms
    { "role": "outer", "name": "外轮廓 1",   "terms": [ { "n": 0, "amp": 160.4, "phase": -2.356 }, … ] },
    { "role": "hole",  "name": "内部孔洞 2", "terms": [ { "n": 0, "amp": 160.0, "phase": -2.356 }, … ] },
    { "role": "outer", "name": "外轮廓 3",   "terms": [ … ] }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `contours[].role` | `"outer"`（外轮廓）或 `"hole"`（内部孔洞）。只影响标注与配色，不影响绘制。 |
| `contours[].name` | 轮廓名称，显示在参数表标题与图例里。 |
| `contours[].terms` | 与单轮廓文档的 `terms` 格式完全一致。 |
| `meta.termCountPolicy` | 项数分配策略说明文本，便于溯源。 |

手写多轮廓文档时，只要保证 `contours` 里每一项都有 `terms` 即可，`role` / `name` / `meta` 都可省略。
想只画外轮廓，删掉 `role: "hole"` 的项即可。

动画中每条轮廓都是**独立的一条「圆上之圆」链条**：各自从原点出发，按面积分配圆的数量，同时旋转、各画各的轨迹。

## 3. 每个参数项的含义

`terms` 里每一项描述**一个匀速旋转的矢量**，也就是动画里的一个圆：

| 字段 | 含义 |
| --- | --- |
| `n` | **整数频率**（可为负）。该矢量每秒转 `n` 圈（归一化时间 t 从 0 到 1 为一圈）。`n=0` 表示不旋转；`n<0` 表示反向旋转。同一个 `|n|` 的正负两项总是成对出现。 |
| `amp` | 圆的**半径**（振幅），单位与 `meta.unit` 一致。 |
| `phase` | **初相**，弧度（若 `meta.phaseUnit` 为 `"deg"` 则为角度）。 |

三项合起来对应复数系数 `c = amp·e^{i·phase}`。绘制时的规则是：

```
起点 = (0,0)
对每一项：
    圆心 = 当前笔尖位置
    该圆上的笔尖点 = 圆心 + amp · (cos(2π·n·t + phase), sin(2π·n·t + phase))
    笔尖移到该点
最终笔尖位置 = 轮廓上 t 时刻的点
```

把 `t` 从 0 连续变到 1，所有笔尖位置连成的闭合曲线就是原轮廓。

也可以不用 `amp`/`phase`，直接给复数系数的实部虚部：

```json
{ "n": 3, "re": -12.5, "im": 4.25 }
```

两者完全等价，工具都支持。同一项里同时出现时以 `amp`/`phase` 为准。

## 3. 数学约定

轮廓视作复平面上的闭合曲线 `z(t) = x(t) + i·y(t)`：

```
z(t) = Σ_k  c_k · e^{ i·2π·n_k·t }

c_k  = (1/N) Σ_{j=0}^{N-1} z_j · e^{ -i·2π·n_k·j/N }
```

离散采样点 `z_j`、采样数 `N` 就是 `meta.pointCount`。系数不做额外归一化，因此 `amp` 的数值单位与轮廓坐标一致，
文档可以直接和原图叠加比对。

约定细节：

- 归一化时间 `t ∈ [0,1)`，`terms` 描述的就是这一整圈的轨迹。
- `n` 的取值范围是 `[-N/2, N/2-1]` 内的整数。
- 只保留振幅最大的 K 项时，轨迹是原轮廓的**最佳 K 项最小二乘近似**：项数越多，尖角越锐利。
- 坐标采用图像坐标系（原点左上、y 向下）时，`n>0` 对应屏幕上的顺时针旋转；界面里的「Y 轴翻转」只改变显示。

## 4. 容错与简写

解析器对以下写法都兼容：

| 写法 | 说明 |
| --- | --- |
| 中文键名 | `说明` / `描述`、`参数` / `系数`、`频率`、`振幅`、`相位`、`轮廓组`、`类型` |
| 三项数组 | `[n, amp, phase]`（只有两项时按 `[n, re]` 处理） |
| 外层包裹 | `{ "doc": { … } }` |
| 角度制 | `"phaseUnit": "deg"` 或 `"相位单位": "度"`，自动换算为弧度 |
| 直接给点 | 用 `"points": [[x,y], …]` 代替 `terms`（单轮廓或多轮廓的每一项都支持），工具会在线做傅里叶展开（项数取 `meta.termCount`） |
| 多轮廓 | 顶层 `contours`（别名 `轮廓组` / `多轮廓` / `shapes`）数组，每项一个轮廓 |

出错时会给出中文提示，指明第几个轮廓、第几项、缺什么，例如：

```
✘ 文档解析失败：第 3 项既没有 amp/phase，也没有 re/im
✘ 文档解析失败：轮廓 2 第 1 项的 n 必须是整数（当前 1.5）
✘ 文档解析失败：轮廓 2：缺少参数数组：需要 "terms": [ … ]，或提供 "points" 轮廓点
✘ 文档解析失败：文档缺少参数数组：需要 "terms": [ … ]，或提供 "points" 轮廓点
```

## 5. 最小示例

单轮廓（一个圆，2 项）：

```json
{
  "format": "fourier-contour",
  "version": 1,
  "description": "最小示例：一个半径为 100、圆心在 (200, 150) 的圆。",
  "terms": [
    { "n": 0, "amp": 250, "phase": 0.6435011 },
    { "n": 1, "amp": 100, "phase": 1.5707963 }
  ]
}
```

- 圆心 `(200, 150)` 写成复数 `200 + 150i`，它的极坐标是 `amp = 250`、`phase = atan2(150, 200) = 0.6435`，即 `n=0` 项。
- `n=1` 项 `amp = 100, phase = π/2` 表示一个半径 100 的旋转矢量。
- 两项相加就是「圆心在 (200,150)、半径 100」的圆。

多轮廓（外圆 + 内孔，各 2 项，画出一个圆环）：

```json
{
  "format": "fourier-contour",
  "version": 2,
  "description": "圆环：外圈半径 100、内孔半径 50，圆心都在 (200,150)。两条轮廓各自是一个圆。",
  "contours": [
    { "role": "outer", "name": "外轮廓",
      "terms": [ { "n": 0, "amp": 250, "phase": 0.6435011 }, { "n": 1, "amp": 100, "phase": 1.5707963 } ] },
    { "role": "hole",  "name": "内部孔洞",
      "terms": [ { "n": 0, "amp": 250, "phase": 0.6435011 }, { "n": 1, "amp": 50,  "phase": 1.5707963 } ] }
  ]
}
```

## 6. 由图像生成文档时的处理链

视图二生成文档时依次执行：

1. **等比缩放**：长边缩放到「处理分辨率」（默认 320 px）。
2. **二值化**：深色 / 浅色 / 透明通道三种前景判定，阈值默认用 Otsu 自动计算。
3. **闭运算**（可选）：先膨胀后腐蚀，把断裂线条、网点连成整体。
4. **连通域分析**：分别标记前景与背景连通域。不与图像边框相连的背景连通域就是**内部孔洞**，
   并归到与它相邻像素最多的那个前景连通域上。
5. **边界跟踪**：对每个前景连通域与每个孔洞做 Moore 邻域跟踪，得到多条有序轮廓链，
   按面积从大到小排序（`最小轮廓面积` / `最多轮廓数` 可过滤碎轮廓）。
6. **等弧长重采样 + 环形平滑**：每条轮廓均匀取 N 点（默认 512），削掉像素级锯齿。
7. **DFT + 截断**：每条轮廓各自展开，保留振幅最大的前 K 项（多轮廓时按 `K·√面积比` 分配，下限 6 项），
   写入 `contours`，并记录覆盖率与重建误差。

已知限制：

- 只跟踪**最外一层的边界**：嵌套更深的层会各自成为独立轮廓（例如同心圆环会得到「外环 / 外环孔 / 内环 / 内环孔 / 中心圆盘」共 5 条），
  但一条轮廓内部的次级细节不会再细分。
- 边界跟踪取的是边界像素中心：外轮廓比真实边缘约小半个像素，孔洞轮廓比真实内边缘约大半个像素
  （面积偏差 ≈ 周长 × 0.5 px）。
- 若轮廓接触图像边缘，说明形状可能被裁切，界面会给出警告。
