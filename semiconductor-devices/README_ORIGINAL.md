# 半导体物理 · 期末总复习（一页一题式放映）

把本学期的**全部题目**（期末复习要点 9 条 × 基础练习 210 个小问 × 作业一～六 31 道大题）汇总成一个
**一页一屏、可离线放映**的复习页：每题给出 **答案 / 解答 / 关联知识点 / 评析**，另附**常用物理参数**与**考前速查**。

> 原卷（`基础练习.pdf`）只有题面、没有答案；六次作业里的部分小问只画了图没写数——
> **这次全部补齐**，并对图题给出读图方法与典型读数。

## 打开方式

双击 `index.html`（Chrome / Edge / Firefox 均可）。

- **必须保持 `index.html` 与 `vendor/`、`data/` 两个文件夹在同一目录**：`vendor/katex/` 是公式字体，`data/*.js` 是题目数据。
- 完全离线：不联网也能渲染公式（KaTeX 已随包内置）。
- 想直接看某一页，可在地址后加锚点，例如 `index.html#p040`（对应作业五第 2 题）。

新增一页的写法：

```js
A.push({
  pid:P(), sec:3, secTitle:'03 · 作业一 · 晶体结构',
  label:'作业一 · 1', title:'页面标题（可用 $公式$）',
  statement:String.raw`<p>题目……</p>`,
  answer:String.raw`<p>答案……</p>`,
  solution:String.raw`<p class="lead"><b>一、…</b> 推导……</p>`,
  kp:['知识点一','知识点二'],
  comment:String.raw`<p>评析……</p>`
});
```

`String.raw` 里可以直接写 LaTeX：行内用 `$...$`，独立公式用 `$$...$$`。

## 说明

- 数值口径：`T=300 K`、`k₀T=0.0259 eV`；Si `nᵢ=1.5×10¹⁰ cm⁻³`、`E_g=1.12 eV`、`ε_r=11.9`（题给 12 时用 12）。
  不同教材的 `nᵢ`、有效质量略有差别，会让末位数字变动，不影响结论与量级。
- 个别图题（原卷附 $E\!-\!k$ 图、MIS 能带图、MOS C–V 图）在原 PDF 中无法直接取数，
  页面给出**读图方法 + 典型读数 + 与题给数值的自洽性检验**；作业六第 4 题还指出了示意图自身的不自洽之处。
