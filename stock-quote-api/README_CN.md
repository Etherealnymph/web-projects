## 项目简介

基于 AKShare 东方财富快照的三个接口：健康检查、36 只常见 A 股目录，以及按逗号分隔代码取实时行情。结果在内存中缓存 30 秒。

## 功能

- `GET /api/health` 健康检查；`GET /api/stocks` 返回 36 只常见 A 股；`GET /api/quotes?symbols=600519,000001` 返回实时行情。
- 使用 AKShare 的 `stock_zh_a_spot_em`（东方财富公开数据），带 30 秒内存缓存。
- 为静态前端开启 CORS；主机与端口可配置。
- 依赖很少：FastAPI、uvicorn 与 AKShare。
