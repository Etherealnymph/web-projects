## Overview

Three endpoints over AKShare's Eastmoney snapshot: a health probe, a catalogue of 36 common A-share symbols, and live quotes for a comma-separated symbol list. Responses are cached in memory for 30 seconds.

## Features

- `GET /api/health` health probe; `GET /api/stocks` returns 36 common A-share symbols; `GET /api/quotes?symbols=600519,000001` returns live quotes.
- AKShare `stock_zh_a_spot_em` (public Eastmoney data) with a 30-second in-memory cache.
- CORS enabled for the static front end; host and port are configurable.
- Small dependency surface: FastAPI, uvicorn and AKShare.
