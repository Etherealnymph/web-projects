### English

Three endpoints over AKShare's Eastmoney snapshot: a health probe, a catalogue of 36 common A-share symbols, and live quotes for a comma-separated symbol list. Responses are cached in memory for 30 seconds.

### 简体中文

基于 AKShare 东方财富快照的三个接口：健康检查、36 只常见 A 股目录，以及按逗号分隔代码取实时行情。结果在内存中缓存 30 秒。
