# 武器切换技能（Weapon Switch Skill）

战斗模式下武器由玩家背包与武器栏共同管理，武器数据来自 `js/data.js` 的 `MW.WEAPONS`，以及 `weapons/*.json` 中导出的模型文件。

## 规则

1. 玩家最多携带 7 件武器，数字键 `1–7` 切换，滚轮也可以循环。
2. 每件武器独立弹匣 `mag`；备弹按口径存放在玩家身上：
   - `light` 5.56mm：手枪 / 冲锋枪 / 步枪 / 激光枪
   - `heavy` 7.62mm：狙击枪 / 重机枪
   - `shell` 12 号霰弹：霰弹枪
   - `rocket` 火箭弹：RPG
3. 开火消耗弹匣，`R` 换弹从备弹池补充；没有备弹时提示。
4. 拾取重复武器会补充该口径备弹，而不是占用武器栏。
5. 右键瞄准：狙击枪进入瞄准镜（FOV 28），其他武器降低散布。
6. 载具武器独立于玩家武器栏：坦克主炮、装甲车机枪、无人机激光、巡逻艇舰炮。
7. 手雷 `G`、地雷 `M` 属于消耗品，放在背包中，受背包容量限制。

## 新增武器

在模型工坊中 AI 生成或导入 JSON，字段：

```json
{
  "id": "custom_x",
  "name": "ZX-9 激光枪",
  "dmg": 58,
  "rpm": 170,
  "mag": 24,
  "spread": 0.0,
  "range": 150,
  "ammo": "light",
  "view": [{ "p": [0, 0, -0.3], "s": [0.1, 0.14, 0.6], "c": "#2d3f4a" }]
}
```

`view` 中每个零件是一个长方体：`p` 位置、`s` 尺寸、`c` 颜色，可选 `"glow": true` 发光。
