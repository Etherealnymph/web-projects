# 模型工坊技能（Model Craft Skill）

模型工坊负责武器建模与人物建模的**生成、预览、导入、导出**。

## 武器模型

输出 JSON：

```json
{
  "name": "电磁狙击枪",
  "desc": "实验型远程武器",
  "dmg": 120,
  "rpm": 60,
  "mag": 6,
  "spread": 0.002,
  "range": 220,
  "ammo": "heavy",
  "color": "#39b8c9",
  "parts": [
    { "p": [0, 0, -0.4], "s": [0.1, 0.14, 0.9], "c": "#39414f" },
    { "p": [0, 0.15, -0.3], "s": [0.06, 0.06, 0.35], "c": "#14181a" },
    { "p": [0, 0.02, -0.95], "s": [0.03, 0.03, 0.2], "c": "#64f0ff", "glow": true }
  ]
}
```

约束：

- 枪口朝 `-Z`，原点在握把附近。
- 整枪长度 0.6–1.3；零件不超过 40 个；颜色不超过 5 种。
- 必须有枪身、枪管、握把；狙击枪加瞄准镜，重武器加弹链/弹鼓。
- 发光件用 `"glow": true`。

## 人物模型

人物是方块组件构成，支持通过调色 JSON 导入/导出：

```json
{
  "name": "霓虹旅人",
  "skin": "#e0b48a",
  "shirt": "#1d3f4a",
  "pants": "#14232b",
  "hair": "#0f2b33",
  "accent": "#5eead4",
  "helmet": "#50603c"
}
```

字段均为可选；`helmet` 留空表示不戴头盔。玩家皮肤会应用到第三人称模型并保存在浏览器。

## 导入/导出

- 武器：`weapons/*.weapon.json`
- 人物：`characters/*.character.json`
- 世界：`worlds/*.miniworld.json`

导出的文件可以直接拖入工坊或设置面板重新导入。
