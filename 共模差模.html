01 / 信号本质

两种信号 · 两条路径

在任何一对导线（如电源的 L 线和 N 线）上，信号都可以分解为两个正交分量： 差模信号在两线之间循环流动， 共模信号则同时同向流过两线、经大地返回。

DIFFERENTIAL MODE

差模信号

DM

大小相等、方向相反，在两根导线之间形成回路。这是有用信号的存在形式 —— 电源传输、数据通信都以差模形式携带信息。

VDM = (VL − VN) / 2
电流方向
L → N
回流路径

COMMON MODE

共模信号

CM

大小相等、方向相同，两根导线同步起伏，通过寄生电容与大地形成回路。 共模信号通常是无用的噪声，是辐射发射的主要来源。

VCM = (VL + VN) / 2

02 / 噪声传播

噪声从哪里来 · 到哪里去

开关电源、变频器、数字电路产生的噪声按传播路径分为两类。 理解它们的回路，是设计滤波器的第一步。

DIFFERENTIAL NOISE

差模噪声

噪声电流在 L 和 N 之间流动，与有用信号走相同的路径。主要来源于开关管动作时 产生的高频纹波，频率通常在 100kHz ~ 10MHz。

→ 来源: 开关管纹波、整流二极管反向恢复
→ 路径: L → 负载 → N（同有用信号）
→ 危害: 影响同线路设备，传导发射超标
→ 抑制: X 电容 + 差模电感
COMMON NOISE

共模噪声

噪声电流同时同向流过 L 和 N，通过寄生电容经大地返回。主要来源于高频开关节点 对地的寄生电容充放电，是辐射发射的元凶。

→ 来源: 开关节点对地寄生电容、变压器寄生
→ 路径: L/N → 大地 → PE
→ 危害: 辐射发射强，易超标，难抑制
→ 抑制: Y 电容 + 共模电感

03 / 滤波元器件

四员大将 · 各司其职

EMI 滤波器由四类核心元器件组成，分别针对差模/共模信号提供低阻抗旁路或高阻抗阻断。 理解它们的物理特性和连接方式，是设计滤波器的基础。

C_X
CX

X 电容

跨接 L-N · 抑制差模

跨接在火线 L 与零线 N 之间，为差模噪声提供低阻抗旁路。 即使失效也不会导致电击危险，可用较大容量（0.1μF ~ 2.2μF）。

安规等级
X1 / X2
耐压
≥ 2.5kV
原理: 高频下电容阻抗 Z = 1/(jωC) 极小， 差模噪声被"短路"在 L-N 之间，无法传到电源侧。
C_Y
CY

Y 电容

跨接 L/N-PE · 抑制共模

跨接在 L-PE 和 N-PE 之间，为共模噪声提供通往大地的低阻抗回路。 失效会导致电击危险，容量严格受限（≤ 4.7nF）。

安规等级
Y1 / Y2
耐压
≥ 4kV
原理: 共模噪声通过 Y 电容旁路到大地， 避免流向电源线。漏电流限制 = 容量限制（I = 2πfCV）。
L_CM
CMC

共模电感

双绕组 · 仅阻共模

两个绕组在同一磁芯上反向绕制。差模电流产生的磁场相互抵消，不呈现电感； 共模电流产生的磁场叠加，呈现高阻抗，阻断共模噪声。

电感量
1 ~ 50 mH
差模电感
极小
原理: L1、L2 同向绕制，差模电流磁场相反相消， 共模电流磁场同向叠加。是共模抑制的主力，且不影响工频供电。
L_DM
DMC

差模电感

单绕组 · 阻差模

单独的电感，串联在 L 或 N 线上。对差模噪声呈现高阻抗，与 X 电容组成 LC 滤波。 由于单独使用会饱和，通常用磁粉芯或开气隙铁芯。

电感量
10 ~ 500 μH
饱和电流
高
原理: 串联在主回路中，与 X 电容形成 π 型低通滤波器， 截止频率远低于开关频率，对高频差模噪声有数十 dB 衰减。

05 / 设计准则

让滤波器真正起作用

一个滤波器能否达到仿真预期的效果，不仅取决于元件参数，更取决于布局、接地与安装工艺。

01

截止频率设计

滤波器的截止频率应远低于开关频率，通常取开关频率的 1/10。 这样在开关频率处能获得 40dB 以上衰减。

fc = 1 / (2π√(LC))
02

共模电感方向

共模电感的两绕组必须正确连接 —— 让负载电流产生的磁场相消， 共模电流产生的磁场相加。接错会立即饱和失效。

L差模等效 ≈ 0 · L共模等效 = 2L
03

布局即滤波

滤波器输入与输出必须物理隔离，避免寄生电容耦合。 元件引脚最短化，Y 电容接地点必须直接连到机壳。
